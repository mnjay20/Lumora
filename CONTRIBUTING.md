# Contributing to Lumora

Thank you for your interest in contributing to Lumora!

## Code of Conduct

Please be respectful, collaborative, and constructive when interacting with the team and other contributors.

## How to Contribute

1. Fork the repository and create a new feature branch (`git checkout -b feature/my-feature`).
2. Adhere to code conventions and formatting guidelines.
3. Commit your changes with clear, descriptive commit messages.
4. Push to your branch and submit a Pull Request.

## Development Workflow

- **Game Client**: Godot 4.x
- **Backend Service**: Python / FastAPI
- **AI Service**: Python / FastAPI with LLM integration
- **Documentation**: Located in `docs/`
